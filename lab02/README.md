# Лабораторна робота №2: Функції вищого порядку, lambda, композиція

**Варіант 1**: Клієнти інтернет-магазину.

## Мета проєкту
Побудова конвеєра перетворень над списком записів без мутації вхідних даних із використанням функцій вищого порядку, зокрема перетворень типу map/filter/reduce, а також функціональної композиції.

## Реалізований функціонал
1. Описано типізовану структуру запису даних клієнта за допомогою `TypedDict`.
2. Розроблено чисті трансформації, що не змінюють вхідні записи: фільтрацію повнолітніх клієнтів, обчислення загальної суми покупок, застосування коефіцієнта для заданого міста та нормалізацію імен.
3. Застосовано генераторні вирази та анонімні функції (`lambda`) для ефективної фільтрації й перетворень даних.
4. Побудовано єдиний конвеєр перетворень за допомогою функції композиції `compose`.
5. Виконано сортування даних за двома ключами із подальшим формуванням рейтингу Top-N.
6. Реалізовано агрегацію даних через функцію `reduce` для отримання трьох статистичних показників: загальної кількості, загальної суми та середнього значення.
7. Розділено архітектуру програми: операції вводу/виводу та CLI-інтерфейс винесено у файл `app.py`, а чисте обчислювальне ядро — у `core.py`.
8. Написано автоматизовані тести за допомогою `pytest` для перевірки коректності роботи конвеєра та гарантії відсутності мутацій.

## Інструкція із розгортання та запуску

1. Створіть та активуйте віртуальне середовище Python:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Для Linux/macOS
   # .venv\Scripts\activate   # Для Windows
2. Встановіть необхідні залежності проєкту:
   ```bash 
   pip install -r requirements.txt
3. Запустіть модульне тестування програми:
   ```bash
   pytest -q tests/
4. Виконайте перевірку якості коду лінтерами та статичним аналізатором типів:
   ```bash
   black .
   ruff check .
   mypy core.py app.py
5. Запустіть програму з використанням параметрів командного рядка:
   ```bash
   python app.py --top 2 --boost-city Delhi --factor 1.1
